# TPI – Organización Empresarial

## PRM – Paseandogs

**Sistema de Planificación de Rutas y Monitoreo en Tiempo Real**

---

## 1. Descripción del proyecto

El presente proyecto tiene como finalidad diseñar y documentar un sistema PRM (Planificación de Rutas y Monitoreo en Tiempo Real) para **Paseandogs**, un emprendimiento dedicado al servicio de paseos caninos.

El sistema busca optimizar la planificación de recorridos, permitir el seguimiento de los paseos mediante tecnología GPS y centralizar la información relacionada con clientes, mascotas, paseadores y rutas.

Este proyecto se desarrolla en el marco de la asignatura **Organización Empresarial** de la Universidad Tecnológica Nacional (UTN).

## 2. Objetivo general

Desarrollar e implementar un sistema PRM que permita optimizar la planificación de rutas de paseo, monitorear los recorridos en tiempo real y mejorar la gestión operativa de Paseandogs.

## 3. Objetivos específicos

- Optimizar la planificación de rutas de paseo.
- Permitir el monitoreo de recorridos mediante tecnología GPS.
- Registrar el inicio y la finalización de cada paseo.
- Centralizar la información de clientes, mascotas, paseadores y rutas.
- Mejorar la organización y el control de las actividades operativas.
- Facilitar el acceso al historial de recorridos realizados.

## 4. Funcionalidades principales del sistema

- **Gestión de clientes:** registro y consulta de información de clientes.
- **Gestión de mascotas:** almacenamiento de datos y características de cada mascota.
- **Gestión de paseadores:** administración de información y asignaciones.
- **Planificación de rutas:** organización de recorridos para los paseos.
- **Monitoreo GPS:** seguimiento de la ubicación durante los recorridos.
- **Registro de paseos:** almacenamiento de horarios de inicio y finalización.
- **Historial de recorridos:** consulta de información de paseos realizados.
