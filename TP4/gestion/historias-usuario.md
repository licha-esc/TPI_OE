# Historias de usuario – Sistema PRM

## HU01 – Registrar clientes

Como administrador, quiero registrar los datos de los clientes, para mantener organizada su información.

## HU02 – Registrar mascotas

Como administrador, quiero registrar los datos de las mascotas, para conocer sus características y necesidades antes de asignar un paseo.

## HU03 – Asignar paseadores

Como responsable de operaciones, quiero asignar paseadores a los paseos programados, para organizar las actividades y los recorridos.

## HU04 – Consultar rutas asignadas

Como paseador, quiero consultar las rutas que tengo asignadas, para conocer los recorridos que debo realizar.

## HU05 – Monitorear paseos mediante GPS

Como cliente, quiero consultar el seguimiento del paseo mediante GPS, para conocer el recorrido de mi mascota.

## HU06 – Registrar inicio y finalización

Como paseador, quiero registrar el inicio y la finalización de cada paseo, para dejar constancia de los horarios del servicio.

## HU07 – Consultar historial de recorridos

Como administrador, quiero consultar el historial de los recorridos realizados, para controlar las actividades y revisar paseos anteriores.
